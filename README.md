# Nav-Bar

Only Css without javascript.

A Navigation Bar (Navbar) is an important part of a website’s frontend. It helps users easily move from one page or section of a website to another.

A typical navbar contains elements such as the website logo, Home, About, Services, Products, Contact, and sometimes a Search bar, Login button, or dropdown menu.

In frontend development, a navbar is commonly created using HTML, CSS:

HTML is used to create the structure of the navbar, such as links, buttons, and menus.
CSS is used to design the navbar, including colors, fonts, spacing, alignment, hover effects, and responsive layouts.
JavaScript can be used to add interactive features, such as opening a mobile menu, dropdown menus, or changing the navbar when scrolling.

A good navbar should be simple, responsive, easy to understand, and consistent across the website. On mobile devices, the navigation links are often hidden behind a hamburger menu to save space.
